TMDb 接入

填入你的 API Key (v3) 或 Read Access Token (v4)，两种都认。
只保存在这台设备的浏览器里（localStorage），不会上传、不会进入网页源码。

元数据语言

影响搜索结果与刷新时抓取的标题、简介。

院线地区

只影响「正在热映」和「即将上映」两个榜单排片。

推荐口味

「推荐」页主要看你书架里的类型和年代分布。
下面两项是补充：人最可能看过的是自己 12–25 岁时上映的片子，母语则决定本土片的比重。留空就不参与。

云同步 · GitHub Gist

用一个 私密 Gist 当存储，手机和电脑共用同一份记录。
需要一个 GitHub Token，只勾 gist 一个权限就够。和 TMDb key 一样只存本机，不会进仓库。

本地备份

没开云同步时，数据只在本浏览器的 localStorage 里 —— 换浏览器、清缓存都会丢。 不管开没开同步，偶尔导出一份 JSON 都是值得的。

导入采用合并策略：同一条目以「更新时间较新」的一方为准，不会误删。

数据校正

找出标着「看完」但正季其实没看全的剧集，改成「在看」。
特别篇不计入判断；完成日期会保留不动。
